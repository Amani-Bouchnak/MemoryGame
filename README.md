# Memory Game

A desktop Memory Game built with **C++17**, **Qt**, and **CMake**.

## Features
- **Configurable board sizes:** Play with 4, 6, 8, 12, or 16 cards.
- **Live game stats:** Tracks moves, matched pairs, and elapsed time.
- **Persistent high scores:** Saves best moves and time per board size locally in `scores.txt` (`std::map`), with instant updates and a score reset option.
- **Card animations:** Smooth reveal transitions and styled card states.
